Ch1 網路簡介

Introduction — 網路的定義、分類、拓撲與傳輸模式

1.1 什麼是網路

網路 (Network) 是將兩台以上的電腦與設備透過傳輸媒介連接，使其能交換資料與共享資源的系統。

網路三要素：設備 (Devices) + 傳輸媒介 (Medium) + 通訊協定 (Protocol)

網路的主要目的

  • 資源共享：印表機、儲存空間、應用程式
  • 資料交換：檔案傳輸、電子郵件、即時通訊
  • 集中管理：伺服器集中控管使用者與安全政策
  • 提高可靠性：備援機制確保服務不中斷
  • 節省成本：共享硬體設備與軟體授權

1.2 網路分類（依規模）

類型全名範圍速度範例
PANPersonal Area Network個人周圍 1-10m1-24 Mbps藍牙、USB
LANLocal Area Network建築物 ~1km10 Mbps - 100 Gbps校園、辦公室
MANMetropolitan Area Network城市 ~10km100 Mbps - 10 Gbps城市 Wi-Fi
WANWide Area Network國家/全球1 Mbps - 100 Gbps網際網路

1.3 網路分類（依角色）

Client-Server 架構

  • 伺服器集中提供服務
  • 客戶端提出請求
  • 集中管理、安全性高
  • 伺服器成本較高

Peer-to-Peer 架構

  • 每台設備兼任客戶端與伺服器
  • 無中央管理節點
  • 成本低、設定簡單
  • 安全性較低

1.4 網路拓撲

拓撲說明優點缺點應用
匯流排 (Bus)所有設備共享一條主幹線佈線簡單、成本低主幹故障全網中斷早期 10BASE2
星狀 (Star)設備連接到中央節點易管理、除錯方便中央設備故障全網中斷現代乙太網路
環狀 (Ring)設備首尾相連成環傳輸穩定、無碰撞單點故障影響全網Token Ring、FDDI
網狀 (Mesh)所有設備互相連接高冗餘、高可靠佈線成本最高骨幹網路
樹狀 (Tree)星狀的層級延伸易擴充、分層管理根節點故障影響大企業網路
混合 (Hybrid)結合多種拓撲靈活彈性設計管理複雜大型網路
現代乙太網路幾乎都使用 星狀拓撲 (Star)，以交換器為中央節點。

1.5 傳輸模式

單工 (Simplex)

資料只能單向傳輸。如：廣播、電視、監視器。

半雙工 (Half-Duplex)

雙方可互傳，但同一時間只能單向。如：對講機。

全雙工 (Full-Duplex)

雙方可同時傳送和接收。如：電話、交換器網路。

Gigabit Ethernet 以上強制使用全雙工模式。

1.6 關鍵術語

頻寬 (Bandwidth)
單位時間內能傳輸的最大資料量，單位 bps
吞吐量 (Throughput)
實際成功傳輸的資料量
延遲 (Latency)
資料從源端到目的端的時間延遲
傳輸時間 (Propagation Delay)
訊號在媒介中傳遞的時間

Ch2 通訊

Communication — 訊號、編碼、傳輸媒介與多工技術

2.1 資料通訊系統五大元件

元件說明範例
訊息 (Message)要傳送的資料內容文字、圖片、聲音、影片
傳送端 (Sender)發出訊息的設備電腦、手機
接收端 (Receiver)接收訊息的設備電腦、手機
傳輸媒介 (Medium)訊號傳遞的通道雙絞線、光纖、無線電波
協定 (Protocol)規範通訊的規則集合TCP/IP、HTTP

2.2 類比訊號 vs 數位訊號

特性類比訊號 (Analog)數位訊號 (Digital)
波形連續平滑波形（正弦波）離散階梯狀方波（0/1）
衰減處理使用放大器，同時放大雜訊使用中繼器，可還原訊號
抗干擾較差，雜訊累積較強，可透過編碼糾錯
應用傳統電話、廣播電腦網路、數位電視
數位傳輸優點：低成本、低錯誤率、易加密壓縮、可整合多種資料類型。

2.3 資料編碼方式

編碼原理特性應用
NRZ1=高電位，0=低電位簡單但可能失去同步低速介面
Manchester每位元中間有電位轉換內建時脈同步早期乙太網路 (10BASE-T)
Differential Manchester位元開始處有無轉換抗干擾性強Token Ring
4B/5B4 位元編碼為 5 位元保證足夠轉換100BASE-TX

2.4 傳輸媒介

有線傳輸 (Guided Media)

  • 雙絞線：UTP（無遮蔽）、STP（有遮蔽），最大 100m
  • 同軸纜線：中心導體 + 絕緣層 + 金屬網，抗干擾佳
  • 光纖：單模（雷射，極長距離）、多模（LED，較短距離）
    高頻寬、低衰減、不受 EMI 干擾

無線傳輸 (Unguided Media)

  • 無線電波：全方向、穿透建築、Wi-Fi (2.4/5/6 GHz)
  • 微波：方向性、需視線 LOS、衛星通訊
  • 紅外線：短距離、無法穿透牆壁
UTP 纜線依頻寬分為 Cat3 (16MHz)、Cat5 (100MHz)、Cat5e (100MHz)、Cat6 (250MHz)、Cat6a (500MHz)、Cat7 (600MHz)、Cat8 (2000MHz)。

2.5 多工技術

技術原理應用
FDM 頻分多工不同訊號使用不同頻率廣播電台、有線電視
TDM 時分多工輪流分配時間槽T1/E1、SONET
WDM 波分多工不同波長的光在同一光纖光纖骨幹（數十 Tbps）
CDMA 碼分多工不同編碼同時同頻傳輸3G 行動通訊

2.6 交換技術

  • 電路交換 (Circuit Switching)：建立專用線路，如傳統電話。優點：穩定；缺點：頻寬浪費
  • 封包交換 (Packet Switching)：資料分割為封包獨立傳送。優點：高效利用頻寬；缺點：延遲不確定
  • 訊息交換 (Message Switching)：完整訊息逐跳轉送 (Store-and-Forward)
現代網路主要使用 封包交換 技術。

Ch3 設備

Equipment — L1 到 L7 網路設備功能、原理與應用

3.1 網路設備層級總覽

設備OSI定址碰撞域廣播域
中繼器 (Repeater)L1無不分割不分割
集線器 (Hub)L1無不分割不分割
橋接器 (Bridge)L2MAC分割不分割
交換器 (Switch)L2MAC每埠分割不分割
路由器 (Router)L3IP每埠分割每埠分割
L3 交換器L2+L3MAC+IP每埠分割可分割
閘道器 (Gateway)L4-L7依協定——
碰撞域 (Collision Domain)：可能發生碰撞的區域。交換器每埠為獨立碰撞域。
廣播域 (Broadcast Domain)：廣播封包能到達的範圍。路由器每埠為獨立廣播域。

3.2 L1 設備：中繼器與集線器

中繼器 (Repeater)

  • 工作在實體層，處理位元訊號
  • 將衰減訊號放大後重新傳送
  • 延長網路傳輸距離
  • 2 埠設備（進/出），不具過濾功能

集線器 (Hub)

  • 多埠中繼器（4-24 埠）
  • 收到的訊號複製到所有其他埠
  • 所有埠共享頻寬與碰撞域
  • 半雙工模式，已被交換器取代

3.3 L2 設備：橋接器與交換器

橋接器 (Bridge)

  • 2-4 埠，連接兩個網路區段
  • 根據 MAC 位址決定是否轉送
  • 建立 MAC 學習表，可分割碰撞域

交換器 (Switch) — 現代網路核心

交換器是多埠橋接器，透過硬體 ASIC 高速轉送：

功能說明
MAC 位址學習記錄來源 MAC 與對應埠號到 MAC 表
轉送/過濾查 MAC 表決定轉送到特定埠或泛洪 (Flooding)
MAC 表老化TTL 通常 300 秒，逾時自動刪除
Store-and-Forward完整接收後檢查 FCS 再轉送，保證正確性
Cut-Through僅讀取目的 MAC 立即轉送，延遲低但無錯誤檢查
VLAN分割為多個邏輯網路，隔離廣播域
STP/RSTP防止網路迴路導致廣播風暴

3.4 L3 設備：路由器

路由器的核心功能：

  • 路由表：記錄目的地網路、下一跳位址、輸出介面
  • 路由來源：直接連接、靜態路由、動態路由 (RIP/OSPF/BGP)
  • 路由選擇：比對目的 IP，選擇最長匹配前綴
  • NAT：私有 IP 轉換為公有 IP
  • ACL：存取控制串列，允許/拒絕特定流量
封包轉送流程：進入 → 檢查目的 IP → 查路由表 (最長匹配) → 修改 TTL 與 Checksum → 從對應介面轉送。

3.5 交換器轉送模式比較

模式延遲錯誤檢查應用
Store-and-Forward高（完整接收）完整 CRC企業核心交換器
Cut-Through低（僅讀 MAC）無高效能運算
Fragment-Free中（讀 64 bytes）檢查衝突片段一般用途

Ch4 通訊協定

Protocol — OSI 模型、TCP/IP、重要協定與埠號

4.1 通訊協定三要素

  • 語法 (Syntax)：資料格式與結構
  • 語意 (Semantics)：欄位意義與控制資訊
  • 時序 (Timing)：傳送時機與速度匹配

4.2 OSI 七層模型

ISO 制定的標準網路架構，由上到下：

層級名稱功能資料單位協定/技術
L7應用層使用者應用服務資料HTTP, FTP, SMTP, DNS
L6表達層資料格式轉換、加密資料SSL/TLS, JPEG, ASCII
L5會議層會話管理、同步資料NetBIOS, RPC
L4傳輸層端對端傳輸、流量控制區段 (Segment)TCP, UDP
L3網路層路由選擇、邏輯定址封包 (Packet)IP, ICMP, ARP
L2資料連結層幀傳輸、MAC 定址幀 (Frame)Ethernet, PPP
L1實體層位元傳輸、電氣訊號位元 (Bit)RS-232, RJ-45
口訣：由上到下「應表會傳網資實」

封裝與解封裝

傳送端：資料 → L7 → L6 → … → L1（逐層加上標頭）
接收端：L1 → L2 → … → L7（逐層移除標頭）

4.3 TCP/IP 模型（四層）

TCP/IP 層對應 OSI主要協定
應用層L5+L6+L7HTTP, FTP, SMTP, DNS, SSH, DHCP
傳輸層L4TCP (可靠)、UDP (不可靠)
網際網路層L3IP, ICMP, ARP
網路存取層L1+L2Ethernet, Wi-Fi, PPP

4.4 TCP 詳細介紹

TCP (Transmission Control Protocol) 是 面向連線、可靠 的傳輸層協定。

TCP 三次握手 (Three-Way Handshake)

Client Server | | |------ SYN (seq=x) ------------>| Step 1: Client 發送 SYN | | |<--- SYN+ACK (seq=y, ack=x+1)--| Step 2: Server 回覆 SYN+ACK | | |------ ACK (ack=y+1) ---------->| Step 3: Client 確認，連線建立 | |

TCP 分段釋放 (Four-Way Handshake)

  • 一方發送 FIN → 另一方回覆 ACK → 另一方發送 FIN → 原方回覆 ACK

TCP 可靠機制

  • 序號 (SN) / 確認號 (ACK)：確保資料按序送達
  • 滑動視窗 (Sliding Window)：流量控制，避免接收端 overflow
  • 擁塞控制：慢啟動 (Slow Start)、擁塞避免、快速重傳、快速恢復
  • Checksum：檢查資料完整性

4.5 UDP 詳細介紹

UDP (User Datagram Protocol) 是 無連線、不可靠 的傳輸層協定。

  • 無握手：直接發送資料，延遲低
  • 無流量控制：傳送速率不受接收端限制
  • 無擁塞控制：可能導致網路壅塞
  • 無序號：封包可能亂序到達
  • 適用：即時應用（串流、VoIP、DNS、DHCP）

4.6 TCP vs UDP 比較

特性TCPUDP
連線面向連線（三次握手）無連線
可靠性可靠（重傳、確認）不可靠（盡力而為）
順序按序送達可能亂序
流量控制有（滑動視窗）無
擁塞控制有（慢啟動等）無
速度較慢較快
標頭大小20-60 bytes8 bytes
應用網頁、郵件、檔案串流、DNS、VoIP

4.8 ARP 與 ICMP

ARP (Address Resolution Protocol)

  • 功能：將 IP 位址解析為 MAC 位址
  • 流程：廣播 ARP Request → 目標回覆 ARP Reply
  • ARP Cache：暫存解析結果，減少廣播
  • 攻擊：ARP Spoofing（偽造 ARP 回覆進行中間人攻擊）

ICMP (Internet Control Message Protocol)

  • 功能：錯誤報告與診斷
  • ping：發送 ICMP Echo Request，測試連通性
  • traceroute：利用 TTL 逐跳探測路徑
  • 類型：Destination Unreachable (3), Time Exceeded (11), Echo (8/0)

4.9 DHCP 運作流程

Discover - Client 廣播尋找 DHCP 伺服器 Offer - 伺服器提議 IP 位址 Request - Client 選擇並請求該 IP ACK - 伺服器確認，租約生效

縮寫：DORA

DHCP 使用 UDP，埠 67 (伺服器) / 68 (客戶端)。

10BASE210 Mbps細同軸 (Thinnet)185mManchester

命名規則：速度 + BASE + 媒介代碼。例：1000BASE-T = 1000 Mbps、基頻、雙絞線。

5.2 CSMA/CD 存取控制

傳統半雙工乙太網路使用 CSMA/CD 控制媒體存取：

Carrier Sense Multiple Access with Collision Detection
  1. 載波偵聽：傳送前先偵聽線路是否空閒
  2. 傳送：空閒則開始傳送資料
  3. 碰撞偵測：傳送時持續監聽是否發生碰撞
  4. Jam 訊號：碰撞發生時傳送 32-bit 擁塞訊號
  5. 指數退避 (Exponential Backoff)：隨機等待後重試
全雙工交換器網路不需要 CSMA/CD，因為發送與接收使用不同線對，不會碰撞。

5.3 乙太網路幀格式

Preamble | SFD | Dest MAC | Src MAC | Type | Payload | FCS 7 bytes | 1 B | 6 B | 6 B | 2 B | 46-1500 B | 4 B
  • 前導碼 (Preamble)：7 bytes，同步訊號 (101010...)
  • SFD：1 byte，幀起始分隔符 (10101011)
  • 目的/來源 MAC：各 6 bytes 硬體位址
  • Type/Length：2 bytes，指定上層協定（IPv4=0x0800, ARP=0x0806）
  • Payload：46-1500 bytes（不足需填充至 46）
  • FCS：4 bytes，CRC-32 錯誤檢查
最小幀：64 bytes（確保 CSMA/CD 正確偵測碰撞）
最大幀：1518 bytes（MTU = 1500）

5.4 MAC 位址

  • 48 位元 (6 bytes)，全球唯一硬體位址
  • 前 24 位元：OUI (Organizationally Unique Identifier)，IEEE 分配給製造商
  • 後 24 位元：製造商自行分配
  • 表示法：00:1A:2B:3C:4D:5E 或 00-1A-2B-3C-4D-5E
  • 廣播位址：FF:FF:FF:FF:FF:FF
  • 多播位址：第 1 個 byte 最低位元為 1

5.5 自動協商 (Auto-Negotiation)

  • 自動偵測對端設備的速度與雙工模式
  • 優先順序（由高到低）：1000BASE-T Full → 1000BASE-T Half → 100BASE-TX Full → 100BASE-TX Half → 10BASE-T Full → 10BASE-T Half
  • 使用 FLP (Fast Link Pulse) 進行協商
如果一端啟用自動協商而另一端固定設定，可能導致 速度/雙工不匹配，造成效能低落與錯誤。

5.6 全雙工 vs 半雙工

特性半雙工全雙工
資料流向同一時間只能單向可同時雙向傳輸
碰撞可能發生（需 CSMA/CD）不會碰撞
有效頻寬= 連線速度= 連線速度 × 2
連線方式使用同一線對使用不同傳送/接收線對

5.7 PoE (Power over Ethernet)

  • 透過乙太網路纜線同時傳輸資料與電力
  • IEEE 802.3af：最大 15.4W
  • IEEE 802.3at (PoE+)：最大 30W
  • IEEE 802.3bt (PoE++)：最大 60-100W
  • 應用：IP Cam、無線 AP、VoIP 電話

Ch7 區域網路

LAN — IEEE 802 標準、VLAN、STP、無線區域網路

7.1 LAN 定義與特性

區域網路 (Local Area Network) 是在有限地理範圍內連接多台設備的通訊網路。

  • 範圍：單一建築或校園
  • 速度：10 Mbps ~ 100 Gbps
  • 所有權：單一組織擁有管理
  • 錯誤率：極低（傳輸品質高）

7.2 IEEE 802 標準家族

標準說明應用
802.1橋接、VLAN、STP交換器網路
802.3乙太網路 (CSMA/CD)有線區域網路
802.11無線區域網路 (Wi-Fi)無線上網
802.15無線個人網路藍牙、ZigBee
802.16寬頻無線WiMAX

7.3 VLAN 虛擬區域網路

VLAN 在單一實體交換器上建立多個邏輯網路：

  • 優點：安全性、減少廣播風暴、管理彈性
  • Port-based VLAN：依據交換器埠號分配 VLAN
  • IEEE 802.1Q：在乙太網路幀插入 4 bytes VLAN 標籤
  • VLAN ID：12 bits，範圍 1-4094（0 和 4095 保留）

802.1Q 標籤結構

TPID (2B, 0x8100) | Priority (3b) | CFI (1b) | VLAN ID (12b)
  • Trunk (主幹)：跨交換器傳送多個 VLAN 流量
  • Access Port：連接到終端設備，屬於單一 VLAN

7.4 STP 生成樹協定

  • 目的：防止交換器網路中的實體迴路導致廣播風暴
  • 演算法：選出 Root Bridge → 選出 Root Port → 選出 Designated Port → Block 其他埠
  • BPDU (Bridge Protocol Data Unit)：交換器之間交換的協定訊息
  • 橋接器 ID：優先權 (2B) + MAC 位址 (6B)，數值越小越優先
  • 埠狀態：Blocking → Listening → Learning → Forwarding

STP vs RSTP vs MSTP

協定收斂時間標準
STP (802.1D)30-50 秒傳統
RSTP (802.1w)1-3 秒快速收斂
MSTP (802.1s)依 VLAN 分組多實例

WLAN 基於 IEEE 802.11 標準：

WLAN 運作模式

  • 基礎架構模式 (Infrastructure)：透過 AP (Access Point) 連接，最常見
  • 臨時模式 (Ad-hoc)：設備直接互連，無需 AP

CSMA/CA

  • 無線網路使用 CSMA/CA（碰撞避免），而非 CSMA/CD
  • 原因：無線環境無法偵測碰撞（隱藏節點問題）
  • 機制：DIFS 等待 → 隨機退避 → RTS/CTS（選擇性）→ 傳送 → ACK

7.6 Link Aggregation

  • 將多條實體鏈路合併為一條邏輯鏈路
  • 標準：IEEE 802.3ad (LACP)
  • 優點：增加頻寬、提供備援
  • 最多可聚合 8 條鏈路

Ch8 網際網路協定

8.1 IPv4 定址

8.3 子網路切割 (Subnetting) & CIDR

將一個大網路劃分為多個小網路，提高位址利用率。

  • 子網路數 = 2借用位元數
  • 可用主機數 = 2剩餘主機位元數 - 2
  • 減 2 原因：網路位址（全 0）和廣播位址（全 1）不可分配給主機
CIDR 表示法：IP 位址 / 前綴長度，如 192.168.1.0/24 表示前 24 位元為網路部分。

VLSM (Variable Length Subnet Mask)

可變長度子網路遮罩，允許在同一個網路中使用不同的子網路遮罩長度，更靈活地分配 IP。

8.4 IPv4 封包結構

IPv4 標頭最小 20 bytes，最大 60 bytes（含 Options）：

8.5 NAT 網路位址轉譯

  • 靜態 NAT (Static NAT)：一對一映射，一個私有 IP 對應一個公有 IP
  • 動態 NAT (Dynamic NAT)：從公有 IP 池中動態取用
  • PAT (Port Address Translation) / NAPT：多對一映射，使用埠號區分不同連線，家用路由器最常用
PAT 優點：節省公有 IP 位址；缺點：無法從外部主動連入內部主機（需埠轉發）。

8.7 IPv6 簡介

  • 128 位元位址空間（IPv4 的 296 倍）
  • 表示法：冒號十六進制，如 2001:0db8:85a3:0000:0000:8a2e:0370:7334
  • 前導零可省略，連續的 0 區段可用 :: 代替（限一次）
  • 內建 IPSec 安全機制
  • SLAAC (Stateless Address Auto-Configuration)：無狀態自動設定 IP
  • 無廣播位址，使用 多播 (Multicast) 取代
  • 無需 NAT（位址充足）

IPv6 位址類型

  • 單播 (Unicast)：一對一通訊
  • 多播 (Multicast)：一對多，取代 IPv4 廣播
  • 任播 (Anycast)：一對最近的一個

IPv4 → IPv6 過渡技術

  • 雙堆疊 (Dual Stack)：同時執行 IPv4 與 IPv6
  • 通道 (Tunneling)：IPv6 封包封裝在 IPv4 中傳送
  • 轉譯 (Translation)：NAT64 / DNS64

8.8 IP 子網路計算範例

範例：將 192.168.1.0/24 切割為 4 個等大小的子網路。

  • 需借用 2 位元（22 = 4 個子網路）
  • 新遮罩：/26 (255.255.255.192)
  • 每個子網路主機數：26 - 2 = 62 台
子網路 1: 192.168.1.0/26 (192.168.1.1 - 192.168.1.62) 子網路 2: 192.168.1.64/26 (192.168.1.65 - 192.168.1.126) 子網路 3: 192.168.1.128/26 (192.168.1.129 - 192.168.1.190) 子網路 4: 192.168.1.192/26 (192.168.1.193 - 192.168.1.254)

網路類型與拓樸

網路類型 (依範圍)

  • PAN：個人網路 (~10m)，如藍牙
  • LAN：區域網路 (~2km)，如家中 Wi-Fi
  • MAN：都會網路 (Metropolitan)
  • WAN：廣域網路 (跨國、Internet)

網路拓樸 (Topology)

  • 星型 (Star)：所有設備連到中央 Switch/Hub
  • 匯流排型 (Bus)：所有設備在一條主幹上
  • 環狀型 (Ring)：頭尾相連成圓環

網路作業環境

對等式 (Peer-to-Peer)

  • 每台電腦平起平坐，是 Client 也是 Server
  • 分散式管理，各節點自行維護資源
  • 建置成本低，無須專門伺服器

主從式 (Client-Server)

  • 專用伺服器提供資源，客戶端發出請求
  • 集中式管理，安全性、備份容易
  • 效能穩定，擴充性強

通訊傳輸模式

單工 (Simplex)

只能單向傳播。如：電視廣播。

半雙工 (Half-Duplex)

雙向但不能同時。如：對講機。

全雙工 (Full-Duplex)

可同時雙向傳播。如：電話、現代交換器。

訊號、調變與多工

訊號三要素

  • 振幅 (Amplitude)
  • 頻率 (Frequency)
  • 相位 (Phase)

調變 (Modulation)

數位調變：ASK (振幅鍵移)、FSK (頻率鍵移)、PSK (相位鍵移)

類比調變：AM (調幅)、FM (調頻)、PM (調相)

多工處理 (MUX)

  • FDM：分頻多工，如廣播電台
  • TDM：分時多工，分配時間片段
  • CDM：分碼多工，獨特編碼解碼
  • WDM：分波多工，專用於光纖

類比轉數位訊號 (ADC)

  1. 抽樣 (Sampling)：取樣類比訊號
  2. 量化 (Quantization)：將樣本對應到離散數值
  3. 編碼 (Encoding)：轉換為數位資料儲存

Switch vs Hub 比較

比較項目Switch (交換器)Hub (集線器)
OSI 層級L2 (資料連結層)L1 (實體層)
傳輸模式單播 (Unicast)廣播 (Broadcast)

價格較貴，現代網路主流便宜，幾乎消失

碰撞網域 vs 廣播網域

  • 碰撞網域 (Collision Domain)：Hub 所有埠在同一網域（會碰撞）；Switch 每埠獨立（不碰撞）
  • 廣播網域 (Broadcast Domain)：兩者都會將廣播封包傳給所有人（除發送者外）

運作邏輯

  • Hub：A 傳給 B 時，複製訊號轉發到所有埠，安全性差且效率低
  • Switch：查 MAC 位址表，針對目標直接傳送，效率高
